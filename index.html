HTML

(HyperText Markup Language)

Es el lenguaje de marcado estándar para crear y estructurar contenido en la web. Es un lenguaje que los navegadores web interpretan para mostrar páginas web. HTML utiliza etiquetas para definir elementos en una página y establecer su estructura y contenido.

Cómo Funciona HTML

Etiquetas HTML:
HTML utiliza etiquetas (tags) para identificar diferentes partes del contenido.
Las etiquetas suelen venir en pares, como <p> y </p>, que indican el inicio y el fin de un párrafo, respectivamente.
Algunas etiquetas, como <img>, no requieren una etiqueta de cierre.
